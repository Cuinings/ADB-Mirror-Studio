# ADB Mirror Studio V1.0.0

首个免费公开版本，面向 Windows x64。所有功能免费，无账户、无试用期、无订阅和无激活。

## 主要功能

- USB、IPv4、IPv6、主机名与 Android 11+ 无线配对
- 流畅、均衡、高清、演示四档 scrcpy 镜像预设
- MP4/MKV 录屏、镜像会话管理和进程回收
- APK 覆盖安装
- 多选、拖放、逐项状态及可取消文件传输队列
- 从设备下载文件或目录，支持双向文件传输
- Android 版本、API、分辨率、电池和存储详情
- PNG 屏幕截图和最近 2000 行 Logcat 导出
- USB 设备切换 ADB TCP/IP、设备重启与历史地址自动重连
- ADB、scrcpy、mDNS 和 PATH 冲突诊断
- Acrylic 界面、主题、自动刷新和本地设置持久化
- 全新应用图标，覆盖 EXE、窗口标题栏、关于页、磁贴、商店图和启动画面
- 修复未打包 WinUI 窗口未显示任务栏图标的问题，并将运行时图标资源随包复制
- 标题栏图标、产品名和版本胶囊使用统一中心线，并进行图标视觉重心校正
- 修复浅色模式下窗口、Acrylic 后景与标题栏配色不同步的问题
- 设置和更新 JSON 使用编译期元数据，兼容裁剪后的 Release 构建
- 首次运行说明、隐私说明、免费使用许可和第三方归属文档
- 通过公开 GitHub Release 免费检查更新
- 修复全局忙碌状态、重复文件传输、自动刷新与手动刷新并发竞态
- 刷新设备列表时保持文件页和工具页的目标设备选择
- 修复镜像会话并发启动/停止与退出观察之间的竞态
- 关闭应用时清理自带 ADB、scrcpy 及镜像会话，避免解压目录被占用
- 修复初始化过程中快速关闭导致异常退出或 ADB 再次启动的问题
- 设置文件损坏、被占用或无权限时安全回退默认设置
- 优化小窗口、高 DPI 和窄屏布局，操作按钮可自动收纳到溢出菜单
- 修复两段式版本标签解析、录屏扩展名大小写和截图失败后的临时文件清理
- 移除与设备中心重复的“无线配对”侧边栏入口，保留设备中心内完整连接与配对功能
- 设备详情的五项独立 ADB 信息改为并行采集，缩短详情加载时间
- scrcpy 标准输出改为固定 64 KiB 尾部缓冲，消除长时间镜像的日志内存增长
- 新增设备视频编码器自动检测与兼容回退，高清模式可优先使用 H.265
- 镜像会话新增采集参数与录制状态展示
- 新增多镜像窗口宫格、横向和纵向自动排列
- 新增返回、主页、最近任务、电源和音量设备快捷控制
- 新增用户应用读取、启动、强制停止和确认卸载
- 新增本次运行期间的录制状态中心
- 修复运行中镜像复用导致“提示已录制但没有生成任务”的状态错误
- 录制中心改为小窗口可滚动布局，增加文件大小、未生成状态和打开目录操作
- 修复设备刷新后镜像会话与录制任务列表不同步的问题
- 停止录制时优先正常关闭 scrcpy，确保 MP4/MKV 完成封装，超时后才强制结束
- 修复用户主动停止录制被误报为失败，以及读取录制文件信息异常导致界面不稳定的问题
- 修复初始化与快速关闭交错时可能记录无效 XamlRoot/标题栏异常的问题
- 发布构建改用独立临时目录，运行旧版软件时也可以安全生成新版压缩包

## 安装

1. 下载 `AdbMirrorStudio-V1.0.0-win-x64.zip`。
2. 核对 SHA256。
3. 完整解压后运行 `AdbMirrorStudio.App.exe`。

发布包为 Windows x64 自包含版本，无需另外安装 Python、.NET、ADB 或 scrcpy。
