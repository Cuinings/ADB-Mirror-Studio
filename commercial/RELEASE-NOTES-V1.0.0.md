# ADB Mirror Studio V1.0.0

`V1.0.0` 是重新整理后的首个完整免费公开版本，合并已经验证的设备连接、镜像录屏、文件管理、诊断、安全更新和隐私保护能力。

## 核心功能

- USB、IPv4、IPv6、主机名连接，以及 Android 11+ mDNS 发现和六位配对码无线配对。
- 最近 10 个无线连接地址仅在本机记忆，始终由用户手动连接，不自动重连。
- 四档 scrcpy 镜像预设、自动视频编码器选择、多会话管理和窗口排列。
- MP4/MKV 录制、录制中心、完成状态、文件大小和输出目录入口。
- APK 覆盖安装、多文件拖放上传、可取消传输，以及设备文件或目录下载。
- 设备详情、截图、Logcat、快捷按键控制和用户应用管理。
- WinUI 3、Desktop Acrylic、浅色/深色主题、小窗口滚动和高 DPI 自适应。

## 应用内安全更新

- 检测后可直接下载 Windows x64 安装包，并显示进度、支持取消。
- 只接受固定 GitHub 仓库的 HTTPS 资产，安装包名称必须与目标版本一致。
- 同时校验 GitHub 元数据中的文件大小和 SHA256；失败时删除临时文件且不会启动。
- 校验通过后启动安装程序并正常关闭当前应用。

## 隐私与发行安全

- 无账户、无遥测、无广告、无在线激活和付费功能。
- 设置、连接历史和崩溃日志仅保存在本机。
- Git 忽略规则与 GitHub Actions 会阻止调试符号、本机设置、日志、凭据、私钥和绝对用户路径进入仓库。
- 正式安装版与便携版不包含 PDB、转储、日志、环境变量文件、密钥材料或本机用户路径。
- 发布构建启用确定性路径映射，并在压缩前执行文件名和二进制内容审计。
