# ADB Mirror Studio V1.0.0

首个免费公开版本，面向 Windows x64。所有功能免费，无账户、无试用期、无订阅和无激活。

## 主要功能

- USB、IPv4、IPv6、主机名与 Android 11+ 无线配对
- 流畅、均衡、高清、演示四档 scrcpy 镜像预设
- MP4/MKV 录屏、镜像会话管理和进程回收
- APK 覆盖安装
- 多选、拖放、逐项状态及可取消文件传输队列
- 从设备下载文件或目录，支持双向文件传输
- Android 版本、API、分辨率、电池和存储详情
- PNG 屏幕截图和最近 2000 行 Logcat 导出
- USB 设备切换 ADB TCP/IP、设备重启与历史地址自动重连
- ADB、scrcpy、mDNS 和 PATH 冲突诊断
- Acrylic 界面、主题、自动刷新和本地设置持久化
- 首次运行说明、隐私说明、免费使用许可和第三方归属文档
- 通过公开 GitHub Release 免费检查更新

## 安装

1. 下载 `AdbMirrorStudio-V1.0.0-win-x64.zip`。
2. 核对 SHA256。
3. 完整解压后运行 `AdbMirrorStudio.App.exe`。

发布包为 Windows x64 自包含版本，无需另外安装 Python、.NET、ADB 或 scrcpy。
