# ADB Mirror Studio V1.0.1

`V1.0.1` 是基于 `V1.0.0` 的免费修订版本，不改变现有功能入口、设置格式或系统要求。

## 修复

- 修复安装或覆盖升级后，已经固定到任务栏的 ADB Mirror Studio 可能继续显示 Windows 空白文件图标的问题。
- 开始菜单、桌面和既有任务栏快捷方式统一使用安装目录中的独立 `AppIcon.ico`，避免 EXE 图标缓存失效。
- 安装和卸载完成后主动通知 Windows 刷新图标缓存；卸载时清理已经失效的固定任务栏快捷方式。
- 应用标题栏、设置页和更新检查统一从程序集版本读取版本号，减少后续发布遗漏。
- 便携包文件名改为从 `Directory.Build.props` 自动读取版本号。

## 兼容性

- 支持从 `V1.0.0` 直接覆盖升级。
- 保留 `%LOCALAPPDATA%\AdbMirrorStudio` 中的现有设置。
- 安装目录、设备连接、镜像、录屏和文件传输操作方式不变。

## 验证

- Release 单元测试：48/48 通过。
- WinUI x64 Release 构建：0 个警告、0 个错误。
- `V1.0.0 → V1.0.1` 静默覆盖升级：退出码 0，现有设置 SHA256 保持不变。
- 将既有固定项模拟为无效图标路径后执行覆盖升级，安装器自动改为独立 `AppIcon.ico`；开始菜单与任务栏快捷方式图标路径一致，任务栏实际显示恢复正常。
- 安装后应用文件版本为 `1.0.1.0`、产品版本为 `V1.0.1`，界面版本胶囊显示 `V1.0.1`。
