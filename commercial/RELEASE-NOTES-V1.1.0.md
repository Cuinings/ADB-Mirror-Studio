# ADB Mirror Studio V1.1.0（开发中）

`V1.1.0` 是保持现有安装、设置和操作方式兼容的免费功能版本。

## 新增

- 在设备工具中直接输入 Android 包名卸载应用，不需要先读取应用列表。
- 卸载前显示目标设备和包名并要求二次确认；包名作为独立 ADB 参数传递。
- 新增绑定“设备工具”当前所选设备的 ADB Shell 高级控制台。
- 支持执行、取消和清除输出；命令和输出只保存在当前界面内，不写入设置或日志。

## 命令执行边界

- 不内置或启动 Windows `cmd.exe`、PowerShell 或其他电脑本机 shell。
- 所有命令固定通过 `adb -s <设备序列号> shell sh -c <命令>` 发送到所选 Android 设备。
- 设备序列号和命令分别作为进程参数传递，不通过 Windows shell 拼接。
- 命令限制为单行、最多 4096 个字符，运行超时为 1 分钟，并支持主动取消。
- ADB Shell 属于高级功能，设备端 `sh` 会解释命令，可能修改或删除设备数据，界面会持续显示警告。

## 验证结果

- 按包名卸载使用 `adb -s <设备> uninstall <包名>`，非法包名会在启动 ADB 前被拒绝。
- 设备命令只启动随包 `adb.exe`，目标序列号通过 `-s` 固定且不会启动 `cmd.exe`。

- WinUI x64/XAML Release 构建：通过，0 个错误。
