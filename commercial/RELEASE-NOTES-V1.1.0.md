# ADB Mirror Studio V1.1.0

`V1.1.0` 是保持现有安装、设置和操作方式兼容的免费功能版本。

## 新增

- 记忆最近 10 个通过应用成功连接的无线 ADB 地址，最近使用的地址自动置顶。
- 无线地址输入框改为可编辑历史下拉列表，可以选择历史地址后手动连接。
- 提供“清除记录”操作；清除历史不会断开当前在线设备。

## 行为调整

- 移除无线设备自动重连开关，应用启动时不会自动执行 `adb connect`。
- 从旧版本升级时保留最后一次成功地址，但会强制关闭旧设置中的自动重连选项。
- 新安装不再预填示例地址，避免误操作连接不存在的设备。
- 设置架构升级为版本 2，历史仅写入本机 `%LOCALAPPDATA%\AdbMirrorStudio\settings.json`。

## 兼容性

- 支持从 `V1.0.0` 和 `V1.0.1` 直接覆盖升级。
- 设备连接、镜像、录屏、文件传输和现有主题设置保持兼容。
- 不增加账户、遥测、订阅、激活或付费功能。

## 验证

- Release 单元测试：53/53 通过，包括历史去重、最近优先、10 条上限、真实旧版 JSON 设置迁移和持久化。
- WinUI x64 Release 构建：0 个警告、0 个错误；XAML 编译已验证历史下拉框、清除按钮和设置说明的事件与绑定。
- 启动初始化路径不再调用连接方法；`adb connect` 只保留在用户点击“连接设备”的处理路径中。
- NSIS 安装器编译成功，产品版本为 `V1.1.0`，文件版本为 `1.1.0.0`。
