# ADB Mirror Studio V1.2.0

`V1.2.0` 是保持现有设备连接、镜像控制和设置兼容的免费功能版本。

## 新增

- 镜像会话卡片新增“开始录制”和“停止录制”按钮。
- 已运行镜像可直接选择 MP4 或 MKV 文件并开始录制，不再要求用户手动停止后重新打开。
- 停止录制后自动恢复普通镜像，并在录制中心显示已完成文件及大小。
- 无线设备显示由“名称/IP:端口”调整为更易读的“名称 IP:端口”。
- 移除关于页面的“打开发布页面”按钮，更新操作统一通过应用内检查、校验、下载和安装流程完成。

## 实现与兼容性

- scrcpy 4.1 不支持运行中动态增减录制器，因此切换时会优雅结束并快速重启该设备的 scrcpy 会话。
- 切换前保存镜像窗口位置和大小，重启后自动恢复；画面会有一次短暂闪断。
- 开始录制前完成扩展名、目录和写入权限预检，避免先关闭镜像再发现路径无效。
- 开始录制失败时自动恢复原普通镜像；旧会话的延迟退出事件不会覆盖新会话状态。
- MP4/MKV 通过正常关闭 scrcpy 完成封装，不使用强制终止作为正常停止路径。
