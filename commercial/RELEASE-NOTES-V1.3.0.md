# ADB Mirror Studio V1.3.0

`V1.3.0` 是保持现有设置、设备连接和镜像能力兼容的免费界面与工作流升级。全部功能继续免费，无账户、试用、订阅、激活或功能分级。

## 页面入口归并

- 主导航精简为“设备、镜像与录制、文件传输、设备工具”，设置继续位于导航底部。
- 原独立诊断和关于页面迁入设置，形成“外观与常规、诊断、更新与数据、关于与许可”四个分区。
- 原设备工具中的下载功能迁入文件传输；上传、从设备下载和 APK 安装现在位于同一任务页面。
- 设备工具划分为常用、应用管理和高级三个分区，ADB Shell 不再占用默认首屏。
- 无线地址连接与 Android 11+ 配对统一归入设备页的“添加或连接设备”区域。

## 设备与安全

- 文件传输和设备工具共享当前目标设备，切换页面不再要求重复选择。
- 当前设备离线时仅回退到在线设备，不触发自动连接或自动重连。
- 长时间传输和设备命令在启动时锁定目标，页面切换不会把任务转移到其他设备。
- 重启、应用卸载和 ADB Shell 确认框显示设备名称以及序列号或 `IP:端口`。
- 设备卡片只突出“打开镜像”，TCP/IP、重启和断开归入更多操作。

## 镜像、录制与状态反馈

- 镜像质量和启动前录制选项迁入“镜像与录制”，设备卡片继续支持一步打开镜像。
- 会话卡片同时显示设备名称和序列号，空会话状态可直接返回设备页。
- 录制中心、运行中开始/停止录制、窗口位置恢复和失败回滚行为保持兼容。
- 页面底部重复状态栏合并为全局状态通知，并按成功、警告和错误显示不同级别。
- 状态通知支持复制详细信息并直接进入诊断；长任务继续显示局部进度、输出和取消入口。

## 布局与辅助功能

- 文件和工具使用页内标签减少纵向堆叠，默认 `1180 × 780 DIP` 窗口首屏优先显示目标设备和主要操作。
- 设备卡片与镜像会话改为纵向自适应结构，禁用非必要的整页水平滚动。
- 页面切换后焦点进入当前页面主要操作，状态变化以礼貌模式通知屏幕阅读器。
- 导航图标不再重复，设备更多操作具备明确的可访问名称。
