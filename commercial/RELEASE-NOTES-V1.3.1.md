# ADB Mirror Studio V1.3.1

`V1.3.1` 是兼容 `V1.3.0` 设置与使用方式的稳定性补丁，全部功能继续免费。

## 修复与改进

- 应用改为单实例运行；重复启动会恢复并激活已有窗口，不会打开第二个客户端。
- 设备卡片中的 Wi-Fi/USB 与在线、离线、未授权状态紧跟设备名称显示。
- 移除设备卡片“更多”菜单，TCP/IP、重启和断开操作直接显示在设备列表中。
- 设备卡片改为信息区与操作区横向对齐，窄窗口下自动切换为两列按钮，减少空白和错位。
- 无线地址为空时点击“连接设备”会提示输入地址，不再误用历史连接记录。
- 启动后不自动填充或连接历史地址，历史记录仍可由用户手动选择。
