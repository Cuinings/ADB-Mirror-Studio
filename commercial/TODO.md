# ADB Mirror Studio 页面入口归并 TODO

本文档记录 `V1.2.0` 之后的页面信息架构优化任务。目标是在不移除现有免费功能、不改变设备安全边界的前提下，将当前 7 个页面入口归并为 4 个主业务入口和 1 个设置入口，并解决默认窗口下内容过长、功能入口重复和下载功能难发现的问题。

## 版本与范围

- 当前基线：`V1.2.0`
- 建议目标：`V1.3.0`
- 版本类型：兼容性 `MINOR` 升级
- 原因：调整导航和操作流程，但不移除功能、不改变设置格式，旧版用户可以直接覆盖升级
- 升级为 `V2.0.0` 的条件：实现过程中必须删除旧工作流、引入无法自动迁移的设置格式，或改变最低系统要求

## 实施状态（2026-08-25）

- 已完成页面入口归并、功能迁移、共享目标设备、危险操作确认、全局状态通知和 README 更新。
- 已增加当前设备在线保留、离线回退和无设备场景的自动化测试。
- 已通过 `Release x64` 编译和 74 项单元测试。
- 已生成并核验 `V1.3.0` 安装版和便携版；尚待完成的复选项主要是实体设备冒烟、不同 DPI/高对比度人工检查、截图和 GitHub 发布后核验。

## 目标导航

| 主入口 | 页面职责 | 内部分区 |
|---|---|---|
| 设备 | 发现、连接和管理设备 | 已连接设备、添加设备、设备快捷操作 |
| 镜像与录制 | 管理实时镜像和录制生命周期 | 质量预设、运行会话、窗口排列、录制中心 |
| 文件传输 | 完成电脑与设备之间的文件任务 | 上传文件、从设备下载、安装 APK |
| 设备工具 | 针对选中设备执行辅助或高级操作 | 常用工具、应用管理、ADB Shell |
| 设置 | 管理应用级配置和支持能力 | 外观与常规、诊断、更新与数据、关于与许可 |

完成后不再保留独立的“诊断中心”和主导航“关于”入口。出现连接、镜像、录制或传输错误时，应从错误提示直接进入设置中的诊断分区。

## P1：页面长度与设备上下文优化

- [x] 常用分区包含设备详情、截图、Logcat 和快捷按键。
- [x] 应用分区包含读取用户应用、启动、强制停止、列表卸载和按包名卸载。

验收标准：

- ADB Shell 和卸载功能不出现在默认“常用”首屏。

### DEVICE-002 统一当前目标设备

- [x] 在 ViewModel 中建立共享的“当前设备”选择状态。

- [x] 长时间任务启动后锁定任务目标，用户切换当前设备不得把运行中任务转移到另一设备。

验收标准：

- 在文件页选择设备后进入工具页，默认选中同一设备。

- 设备断开、重连和序列号变化时不会保留失效选择。

- [x] 录制中心不与普通文件传输合并；录制中心仍负责会话状态、封装结果和失败信息。
- [x] 诊断不并入纯“关于”内容；诊断必须是设置内独立、可执行的支持分区。
- [x] 不新增独立“无线连接”主导航，避免与设备中心重复。
- [x] 不为共享设备选择引入自动连接或自动重连。
